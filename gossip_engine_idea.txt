GOSSIP ENGINE FOR AI COGNITION — IDEA NOTES
============================================
Captured from conversation | May 2026


CORE HYPOTHESIS
---------------
Current LLM architectures are fundamentally limited because they operate as static
next-token predictors with centrally orchestrated reasoning. Genuine creativity,
invention, and open-ended intelligence may require something closer to evolutionary
and memetic systems — specifically, a population-based "gossip engine" for AI cognition.


THE PROBLEM WITH CURRENT LLMs
------------------------------
- Static next-token predictors; no persistent evolving state
- Centralized, hierarchical, deterministic reasoning
- Converge too quickly toward probable/safe answers
- No mutation, recombination, or selection of ideas
- No cultural memory or idea lineages
- Cannot generate genuinely novel abstractions or paradigm shifts
- Lack intrinsic motivation or curiosity


THE GOSSIP ENGINE PROPOSAL
---------------------------
A population-based cognitive architecture where:

  - Large populations of semi-autonomous agents operate in parallel
  - Local peer-to-peer communication replaces central orchestration
  - Agents maintain persistent memories and evolving idea lineages
  - Ideas undergo mutation and recombination across agents
  - Selection mechanisms filter by: usefulness, predictive accuracy,
    novelty, compression efficiency, or external grounding
  - Controlled noisy exploration prevents premature convergence
  - Agents compete for compute/attention/resources
  - Reality grounding via experiments, simulations, or tool use

The system functions more like:
  - An evolving scientific community
  - A biological ecosystem
  - Civilization-scale cognition
  ...rather than a single chatbot.


AGENT-AS-NEURON ARCHITECTURE
------------------------------
Key insight: treat each LLM agent as a neuron in a larger network.
Intelligence is not IN any single agent — it emerges from connectivity
dynamics across the population.

Biological mappings:
  - Sparse activation       → only ~1-5% of agents fire at any moment
  - Weighted connectivity   → learned influence between agents (trainable)
  - Layered hierarchy       → early agents: perception/retrieval;
                              middle agents: abstraction/reasoning;
                              late agents: planning/evaluation
  - Lateral inhibition      → active agents suppress weak/redundant ones
                              (winner-take-all dynamics, sharpens output)
  - Hebbian learning        → agents that collaborate successfully
                              strengthen their connection (local credit
                              assignment — avoids global backprop problem)
  - Emergent specialization → functional roles discovered, not hand-designed

Key difference from biological neurons:
  Each agent is a powerful LLM, not a simple threshold unit.
  This means fewer agents are needed; connectivity matters less
  because each node compensates with internal depth.


CODED INTER-AGENT COMMUNICATION
---------------------------------
Problem with plain language between agents:
  - Lossy compression of internal state
  - Semantic drift under paraphrase
  - Discretization breaks gradient flow
  - Manipulation surface (rhetoric, not just semantics)

Proposed alternatives:

  1. CONTINUOUS EMBEDDING VECTORS
     - Agents emit z ∈ ℝᵈ instead of tokens
     - Fully differentiable (gradients flow backward)
     - High bandwidth, no semantic drift
     - Not human-interpretable
     - Precedent: DIAL (Foerster et al. 2016), CommNet

  2. STRUCTURED SYMBOLIC CODES
     - Typed predicate logic or domain-specific schema
     - Example: {relation: (A,B), mechanism: X, confidence: 0.6,
                  evidence_ids: [e1,e4], type: "hypothetical"}
     - Human-interpretable, enables formal recombination
     - Bounded expressiveness; needs meta-level schema extension

  3. SHARED CODEBOOK (VQ-style)
     - Finite vocabulary of learned concept-vectors (like VQ-VAE)
     - Communication = sequence of codebook indices
     - Discrete, efficient, compositional if hierarchically structured
     - Shared across all agents → solves semantic drift
     - Codebook = collective memory of the population
     - Codebook evolution: mint new codes, retire old ones,
       split ambiguous codes, merge redundant ones
     - Analog: how scientific communities develop shared vocabulary

  4. ACTIVATION PATCHING / DIRECT STATE INJECTION
     - Agent A's internal activations injected directly into Agent B's
       residual stream — no serialization
     - Requires representational alignment (learned linear projection W_AB)
     - Maximally information-dense, fully differentiable
     - Completely opaque to human inspection
     - Precedent: representation engineering (Zou et al. 2023),
       model stitching (Lenc & Vedaldi)


CONCRETE ARCHITECTURE SKETCH
------------------------------
Each agent has three interfaces:

  INPUT:
    - Raw context (text, data)
    - Structured symbolic messages from upstream agents
    - Injected activation vectors from peer agents

  CORE:
    - Standard transformer processing combined input

  OUTPUT:
    - Primary output (text or action)
    - Continuous embedding of current belief state
    - Set of codebook indices for key activated concepts

Network dynamics:
  - Runs recurrently for K timesteps before readout
  - Each timestep: active agents broadcast embedding + codebook indices
  - Neighbors gate incoming signals by learned relevance weights
  - Sparse activation: only high-signal agents fire
  - Output layer reads from most-activated high-level agents

Training objectives (dual):
  1. Task performance (external reward or supervised signal)
  2. Communication efficiency (rate-distortion: minimize message
     description length while maximizing task performance)
  → Second objective drives codebook to be compact and expressive


EXPECTED EMERGENT BEHAVIORS
-----------------------------
If the architecture works as theorized:
  - Spontaneous functional specialization by network position
  - Compositional codebook (complex = combinations of simple codes)
  - Phase transitions in collective capability at critical connectivity
  - Graceful degradation under agent dropout
  - Cross-domain discovery via recombination of specialist agents


KEY OPEN PROBLEMS
------------------
1. FITNESS EVALUATION
   How do you evaluate whether an idea is good?
   - "Usefulness" is circular without a grounded task
   - "Novelty" selects for weird, not valuable
   - Kolmogorov complexity is uncomputable
   - Best current answer: fast verifiable simulators
     (limits applicability to domains with fast ground truth)

2. CREDIT ASSIGNMENT ACROSS AGENTS
   Which agent's contribution caused downstream success?
   Hebbian local updates partially dissolve this, but not fully.

3. PREMATURE CONVERGENCE VS. SEMANTIC DRIFT
   Both are failure modes simultaneously.
   Quality-Diversity methods (MAP-Elites) offer partial solutions.

4. CODEBOOK EXTENSION FOR NOVEL CONCEPTS
   Paradigm-shifting ideas don't fit existing codes.
   Need: grounding new codes in shared experiences
   (simulation results, experimental outcomes, cross-agent activations)
   This links to embodiment/reality-grounding — same problem,
   different angle.

5. ADVERSARIAL MEMETIC DYNAMICS
   Selection for "ideas that spread" ≠ selection for "true ideas"
   (same failure mode as social media algorithms)
   Needs formal mechanism design and truth-tracking mechanisms.


SUPPORTING EVIDENCE
--------------------
FOR the direction:
  - Immune system: population of agents with mutation + clonal selection
    → solves open-ended recognition problems (existence proof)
  - FunSearch (DeepMind 2023): evolutionary outer loop + LLM proposals
    → discovered genuinely novel mathematical constructions
  - Global Workspace Theory (Dehaene): competition among neural coalitions
    for broadcast access → maps to attention/compute competition
  - Henrich's cultural ratchet: human intelligence is population-level,
    not individual
  - Dunbar: cross-domain analogies are the primary source of breakthrough
    insights in science → your system mechanically implements this

AGAINST / COMPLICATING:
  - Biological evolution is extremely slow without fast fitness oracles
  - Memetics: ideas selected for spreadability, not truth
  - Paradigm shifts require representational change, not just better search
    (Kuhn, Ohlsson on insight) — gossip engine is better optimizer
    within fixed representation; doesn't solve hardest creative problems
  - Compute cost: O(N × T × inference_cost) — needs 1000x better solutions
    to justify 1000x more compute vs. single model


RELATION TO PRIOR ANALYSIS (LLM LIMITATIONS)
----------------------------------------------
This architecture directly addresses several gaps identified earlier:

  Gap                      | This approach
  -------------------------|------------------------------------------
  No long-term memory      | Persistent agent memories + codebook
  No intrinsic motivation  | Competitive dynamics + prediction error
  No causal world model    | Reality grounding via simulation
  Premature convergence    | Population diversity + lateral inhibition
  No abstraction formation | Emergent codebook + compositional codes
  No credit assignment     | Hebbian local updates
  Plain language limits    | Coded communication protocols


HONEST SUMMARY
---------------
This is NOT a replacement for scaling transformers.
It is an OUTER LOOP in which transformer models are components.

Best framing:
  "Build evolutionary outer loops with LLM components in domains
   with verifiable fitness, tight reality grounding, and formal
   diversity maintenance mechanisms."

Current state of the art for this: FunSearch (DeepMind, 2023)
Next step: extend to more open-ended domains while solving
fitness evaluation and credit assignment.

The neuron analogy reframes the question productively:
  NOT "how do we make individual agents smarter"
  BUT "what connectivity dynamics produce emergent collective intelligence"

That is the right question — and neuroscience has partial answers
that can be directly imported into this design space.
